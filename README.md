# 💻 LeetCode Solutions & Programming Practice

This repository contains my **coding practice, LeetCode solutions, DSA implementations, and programming fundamentals** that I work through while improving my problem-solving skills.

It is **not strictly a LeetCode-only repository**. Alongside solutions to coding problems, I also keep implementations, experiments, and practice programs that help me understand programming concepts more deeply.

The goal is simple:

Where applicable, solutions include analysis of:

```text
Time Complexity
Space Complexity
```

Understanding the trade-offs between different approaches is an important part of my DSA practice.

For example:

